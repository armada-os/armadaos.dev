# RPCS3

RPCS3 is a Sony PlayStation 3 emulator.

The latest version can be installed via the [Armada Store](../../using-armada/armada-store.md).

## BIOS

RPCS3 requires the official PS3 firmware package, `PS3UPDAT.PUP`, to be installed through the emulator.

## Paths

### ES-DE

| | |
| --- | --- |
| **ROM Folder** | `ps3` |

### Emulator

| | |
| --- | --- |
| **Emulator ROM Folders** | `/var/home/armada/.config/rpcs3/games` |
| **App Path** | `/var/home/armada/Applications/rpcs3.AppImage` |
| **Config Folder** | `/var/home/armada/.config/rpcs3` |
| **Config File** | `/var/home/armada/.config/rpcs3/config.yml` |
| **Installed Titles** | `/var/home/armada/.config/rpcs3/dev_hdd0/game` |
| **Saves Folder** | `/var/home/armada/.config/rpcs3/dev_hdd0/home/00000001/savedata` |
| **States Folder** | `/var/home/armada/.config/rpcs3/savestates` |

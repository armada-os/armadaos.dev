# Vita3K

Vita3K is an experimental Sony PlayStation Vita emulator.

The latest version can be installed via the [Armada Store](../../using-armada/armada-store.md).

## BIOS

Vita3K requires the official PS Vita firmware to be installed through the emulator. For best compatibility, install both the main firmware package and the additional font package.

## Paths

### ES-DE

| | |
| --- | --- |
| **ROM Folder** | `psvita` |
| **ROM Files** | `.psvita` |

### Emulator

| | |
| --- | --- |
| **App Path** | `/var/home/armada/Applications/Vita3K.AppImage` |
| **Config Folder** | `/var/home/armada/.config/Vita3K` |
| **Config File** | `/var/home/armada/.config/Vita3K/config.yml` |
| **Installed Titles** | `/var/home/armada/.local/share/Vita3K/Vita3K/ux0/app` |
| **Saves Folder** | `/var/home/armada/.local/share/Vita3K/Vita3K/ux0/user/00/savedata` |

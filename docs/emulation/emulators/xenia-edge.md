# Xenia Edge

Xenia Edge is an experimental Xenia fork for Xbox 360 emulation.

Xenia Edge is not currently available via the [Armada Store](../../using-armada/armada-store.md). The official Linux x86 AppImage may be run with FEX.

## BIOS

Xenia Edge does not require a BIOS file.

## Paths

### ES-DE

| | |
| --- | --- |

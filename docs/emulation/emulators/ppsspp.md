# PPSSPP

PPSSPP is a Sony PlayStation Portable emulator.

The latest version can be installed via the [Armada Store](../../using-armada/armada-store.md).

## BIOS

PPSSPP does not require a BIOS file.

## Paths

### ES-DE

| | |
| --- | --- |
| **ROM Folder** | `psp` |
| **ROM Files** | `.chd .CHD .cso .CSO .elf .ELF .iso .ISO .pbp .PBP .prx .PRX .7z .7Z .zip .ZIP` |

### Emulator

| | |
| --- | --- |
| **App Path** | `/var/lib/flatpak/app/org.ppsspp.PPSSPP` |
| **Config Folder** | `/var/home/armada/.var/app/org.ppsspp.PPSSPP/config/ppsspp/PSP/SYSTEM` |
| **Config File** | `/var/home/armada/.var/app/org.ppsspp.PPSSPP/config/ppsspp/PSP/SYSTEM/ppsspp.ini` |
| **Saves Folder** | `/var/home/armada/.var/app/org.ppsspp.PPSSPP/config/ppsspp/PSP/SAVEDATA` |
| **States Folder** | `/var/home/armada/.var/app/org.ppsspp.PPSSPP/config/ppsspp/PSP/PPSSPP_STATE` |

# ScummVM

ScummVM runs supported adventure and RPG game data files without requiring the original game executables.

The latest version can be installed via the [Armada Store](../../using-armada/armada-store.md).

## BIOS

ScummVM does not require a BIOS file. You only need the original game data files for a supported title.

## Paths

### ES-DE

| | |
| --- | --- |
| **ROM Folder** | `scummvm` |
| **ROM Files** | `.scummvm .SCUMMVM .svm .SVM` |

### Emulator

| | |
| --- | --- |
| **App Path** | `/var/lib/flatpak/app/org.scummvm.ScummVM` |
| **Config Folder** | `/var/home/armada/.var/app/org.scummvm.ScummVM/config/scummvm` |
| **Config File** | `/var/home/armada/.var/app/org.scummvm.ScummVM/config/scummvm/scummvm.ini` |
| **Saves Folder** | `/var/home/armada/.var/app/org.scummvm.ScummVM/data/scummvm/saves` |
